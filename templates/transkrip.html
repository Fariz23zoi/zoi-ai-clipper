Transkrip lewat Google Colab

Untuk laptop yang lambat. Google Colab meminjamkan komputer ber-GPU secara gratis lewat browser; cukup akun Google, tanpa API key. Transkrip dibuat di sana, lalu diimpor ke ZOI.

1. Unduh audionya

ZOI mengunduh suara videonya saja (sekitar 0,5 MB per menit).

2. Buat transkrip di Colab

  1. Unduh notebook ZOI: Unduh notebook (.ipynb)
  2. Buka colab.research.google.com, masuk dengan akun Google, lalu pilih File → Upload notebook dan pilih file notebook tadi.
  3. Pilih Runtime → Change runtime type → T4 GPU, lalu Save.
  4. Pilih Runtime → Run all. Saat diminta, pilih file audio dari langkah 1.
  5. Setelah selesai, file .srt terunduh otomatis ke laptop.

GPU gratis Colab dibatasi waktu pemakaian dan kadang sedang tidak tersedia. Bila tidak ada GPU, notebook tetap jalan tetapi jauh lebih lambat.
